## Lý thuyết 
Interface dùng để định nghĩa hình dáng của đối tượng (object) => cần biết có những thuộc tính nào, kiểu dữ liệu là gì 

Class là bản thiết kế tạo ra các objects => giúp gom nhóm dữ lieu (properties) + methods cùng 1 chỗ => quản lý trạng thái (state) của ứng dụng
