# Image assets

Các ảnh trong thư mục này được tách từ file snapshot
`Trang chủ - Sun_ Inc. Tuyển Dụng.html` để trang thực hành không phụ thuộc vào
ảnh nhúng base64.

## Cấu trúc

- `common/`: logo, favicon và biểu tượng footer.
- `business/`: ảnh minh họa lĩnh vực kinh doanh.
- `projects/`: ảnh ba dự án SSK, HARUTAKA và KURASHICOM.
- `careers/`: ảnh nền khu vực cơ hội nghề nghiệp.
- `environment/`: ảnh môi trường làm việc.
- `news/`: ảnh các bài viết văn hóa và sự kiện.

Video hero không lưu trong repo. `index.html` dùng trực tiếp hai nguồn video
desktop/mobile của website Sun Asterisk.
